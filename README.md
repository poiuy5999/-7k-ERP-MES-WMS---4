集成 ERP、MES、WMS 的一体化管理系统，融合企业资源计划、生产制造执行、仓储仓库管理三大核心模块，配套移动端操作端，附带完整安装部署文档，源码支持二次开发，面向工贸制造企业，打通采购、生产、车间执行、仓储出入库全业务流程。

WMS 仓储模块是仓库业务核心，覆盖入库、出库、盘点、移库、库位管理全场景。支持条码扫码作业，物料、成品绑定对应库位，精准核算库存数量，减少错发、漏发问题。配套移动端，仓管人员可使用手持设备现场扫码，完成收货、拣货、盘点等操作，数据实时同步后台，告别纸质单据。

MES 生产模块对接车间业务，管理生产工单、工序流转、物料领料、生产报工与成品入库。全程记录生产过程数据，追踪物料从领料加工直至成品入库，实现生产进度可视化管控。ERP 模块统筹企业进销存、财务单据、供应商与客户资料，管理采购订单、销售订单、应收应付账款，打通生产、仓储、财务数据，实现业务一体化联动。

管理后台支持维护物料档案、BOM 配方、车间工序、仓库库位，查看库存台账、生产进度、经营统计，各类业务报表支持导出。移动端可供仓管、车间人员随时随地提交单据、查询库存、上报生产数据。系统采用模块化架构，可按需调整业务流程，适配不同制造行业需求。配套部署文档包含服务器环境、数据库配置、前后端部署、移动端打包教程，降低项目实施门槛。

整套一体化系统串联采购、生产、车间执行、仓储出入库全流程，搭配移动端现场作业能力，减少手工纸质单据，提升库存准确度与车间生产管控能力，助力生产型企业实现数字化转型升级。
